# R-数字藏馆

解压后双击 index.html 进入藏馆。首页页脚可重放开场。导航包含展厅、书籍、数字雕塑和开发历史。点击导航栏「唱片」后可选择 Music.zip 中的 49 首歌曲。音乐已包含在压缩包内，解压后可离线播放。

游戏展厅默认进入滚动展映。使用滚轮、触摸、前后按钮或方向键移动镜头；「全部封面」打开可搜索的 23 幅 AI 封面索引。点击作品后，文字先覆盖旧画面，再穿过字形揭示详情。开启减少动态时直接显示静态封面。开发历史可按四个阶段切换。

数字雕塑收录九件展品，包括《黄金藤蔓》、茉子半身像、白龙娘、三件外部模型及最初的三件作品。前三件定制展品支持下载 GLB。黄金藤蔓可切换三视角、灰模和原图。九件展品均可从三维展廊进入。用拖动调整视角，用 WASD 或屏幕上的方向键行走。选择展台进入作品。光珠落地后会反弹，空间声由参观者主动开启。

十八本书包括六部随包中文全文、六部起点正版书目及六部原有馆藏。书籍支持空间展映和卡片书架。书籍支持离线中文 TXT 正文、图书平台在线样章、中文阅读入口和本机 EPUB。具体操作见 docs/NOVELS.md。键入 aurora 可切换极夜灯光。系统开启「减少动态」时会简化开场与转场。

共同参观可在装有 Node.js 的电脑上运行 node serve.mjs，然后访问 http://127.0.0.1:4173 。在同一服务打开两个窗口，分别点击页脚「共享展厅光标」，在同一个展厅移动鼠标即可看到另一位参观者的位置。默认仅监听本机，无需账号，不保存光标历史。开启后也可在「馆内交谈」发送临时消息，同一服务的参与者可见；断开后不保留会话记录。

参考项目、实际采用的代码及许可见站内「开源许可」。
