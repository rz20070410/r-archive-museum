# 展映版视觉验收

| 操作 | 核对画面 |
| --- | --- |
| 首页移动鼠标，经过标题、水晶和空白区域 | 指针不排放烟雾、粒子或光点。观察窗内部的微弱流场随滚动变化。 |
| 进入展厅并滚动 | AI 封面位于不同深度，镜头向下一幅作品前进。物体随镜头产生透视变化，片名、序号、中文标题和入口同步更新。 |
| 点击「全部封面」 | 可以看到或搜索 23 幅 AI 游戏封面，点击任一作品可进详情。 |
| 展映时切换分类 | 英文分类词与中文标签从背景升到前景；印色底完全盖住作品后，才替换分类数据。 |
| 点击「查看展品」 | 背景片名向前放大，多行中英文错位、旋转并遮挡旧画面，字形镂空放大后显出作品详情，标题逐字入场。顶栏留在原位。 |
| 移动指针经过展映舞台 | 展映标题的字距与镜头视角轻微改变。没有鼠标尾迹。 |
| 开发历史 | 全屏玻璃 R 主视觉；四个历史篇章可切换配图与正文；下方保留饶智、GPT 娘茉子、大肥鱼的署名。 |
| 小屏或减少动态 | 支持触摸滚动与按钮移动。减少动态时使用同一套封面、跳过文字遮罩，游戏入口保持可用。 |

参考录屏一用于确定文字换场的顺序和印色。录屏二用于定位并删除遮挡内容的烟雾鼠标。展厅镜头参考 [Cinematic 3D Scroll](https://github.com/JosephASG/codrops-cinematic-scroll-animations)，使用适配当前离线游戏数据的新场景；文字逻辑改编自 [Codrops Kinetic Typography](https://github.com/codrops/KineticTypePageTransition)。图层参考 [GIATS](https://giats.me/)，导航图标按 [Apple 图标分层说明](https://developer.apple.com/design/human-interface-guidelines/app-icons) 设计。
